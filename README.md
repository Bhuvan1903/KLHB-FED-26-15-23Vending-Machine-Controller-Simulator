# **Project Abstract:**
The Vending machine controller simulator is a java based application designed to simulate the basic functioning of a vending machine. The system allows users to select the products from the available menu and enter the required quantity. Based on the selected products and the quantity the system automatically calculated the amount and displays the total amount to be paid. The project provides a simple user friendly way of understanding the process of product selection and price calculation. This system used basic concepts of java programming such as Scanner class, conditional statements, switch case, break , arithmetic operators and variables. This project helps in understanding the practical application of basic java programming concepts in the developing a automated vending machine .
